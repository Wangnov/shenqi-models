# 野生狗奶

蓝白色 200 毫升纸盒，带折耳、热封纹、纸层切边和吸管孔。

![野生狗奶](../../docs/previews/wild-dog-milk.png)

- [可编辑 Blender 工程](model.blend)
- [自包含 GLB](model.glb)
- [细节预览](../../docs/previews/wild-dog-milk-detail.png)

| 项目 | 规格 |
| --- | --- |
| 比例估算尺寸 | 62 × 40 × 100 mm |
| 模型求值三角面 | 272,636 |
| 已完成主图 | 1000 × 1000 |

GLB 的贴图长边为 4K；Blender 保留更高分辨率的内嵌贴图、程序化纸面材质和旋转动画。

贴图已内嵌。使用 Blender 5.0.1 或兼容版本打开工程，在图像编辑器中选择贴图并另存即可导出。几何、UV、材质和相机可编辑；GLB 用于其他软件导入，不含摄影棚及 Blender 专用程序化材质。工程默认使用 CPU 渲染，可根据本机配置切换 GPU。

不可见部位按包装结构补建，尺寸未经过实物测量。来源及重绘说明见 [参考资料](../../docs/REFERENCES.md)。
