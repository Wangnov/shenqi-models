# 三神器宇宙

围绕永恒、空间与时间的三个实时 Three.js 场景。

## 运行

需要 Node.js 22 或更新的受支持版本。

```bash
cd web
npm ci
npm run dev
```

生产构建使用 `npm run build`，预览使用 `npm run preview`。`dist/` 可以部署到任意静态托管服务；构建采用相对资源路径，支持 GitHub Pages 的仓库子路径。

## 交互

| 场景 | 操作 |
| --- | --- |
| 永恒 · 野生狗奶 | 宇宙以 36 秒周期诞生、膨胀、热寂和重生，牛奶自身不漂浮、不溶解；拖动仍可主动检查模型。“推进宇宙生灭”平滑加速后回到原速，也可暂停演化。 |
| 空间 · 菊花饮料 | “展开十倍空间”打开十个空间单元，以每份 250 mL 的视觉单位呈现包装上的 2500 mL。尺度条连续展开，九个副本围绕中央原件，从不同角度展示包装；这是艺术化的容积表达。 |
| 时间 · 春秋肠 | 一分钟压缩三十年；三维日期刻度标出 2008 过期、2018 生产，以及两者之间的负十年。拖动时间轴、倒流或暂停，观察先过期后诞生的悖论与残影。 |
| 通用 | 拖动旋转，滚轮或双指缩放；复位按钮或双击场景以缓动恢复视角。沉浸时平滑居中、隐藏全部 UI；短暂提示渐隐后，双击或 Esc 退出。底部导航和左右方向键切章，滚轮始终只缩放。右上角开启本章配乐。 |

支持 `#eternity`、`#space`、`#time` 深链接。手机采用独立构图并降低粒子数量及像素比。页面隐藏时停止渲染并暂停声音；减少动态效果偏好下关闭自动运动。

## 技术与资产

- Three.js、TypeScript、Vite；GLTFLoader、MeshoptDecoder、模型表面采样、GPU 粒子动画、HDR 辉光与程序化空间雾。后期渲染目标使用 MSAA，并通过 SMAA 平滑细线；粒子采用稳定亮度的柔和足迹。
- `public/models/` 为独立的网页模型，几何经过简化与 Meshopt 压缩，贴图为最高 2048 像素 WebP；原始可编辑资产仍在根目录的 `models/`。
- `npm run assets` 可从根目录原始 GLB 重新生成网页资产。尺寸统计保存在 `public/models/manifest.json`。
- 所有运行资源从本站加载；不依赖在线字体、远程纹理或在线生成服务。三章配乐由 Gemini 网页版生成，文件与说明在 `public/audio/`；网页不包含生成服务密钥。
- 配乐默认关闭，点击后按需加载本章 MP3。章节之间交叉淡入淡出，音频首尾做 2 秒交叉混合以平滑循环；页面隐藏时暂停音频。时间控制只作用于视觉，配乐保持原速。
- 光带边缘对插值范围做显式钳制，避免负数的非整数幂产生 NaN 并扩散为整帧黑闪。时间动画使用连续时钟，仅时间轴读数每 60 秒循环。
- 透明袋使用 glTF transmission 材质。春秋肠卡扣在网页中使用各向同性金属高光，避免退化 UV 切线导致 HDR 后期出现非有限像素。
- 三个场景共享渲染器和环境贴图，按需加载，首幕显示后后台预加载其余模型。低画质降低粒子数量和像素比；帧率目标需结合实际设备测试。
- 远景巨环、星系、行星轮廓与实例化遗迹提供世界空间中的尺度参照；缩放时有真实透视变化。永恒的宇宙生灭、空间的十倍展开、时间的形态演变都是实时几何与着色器效果。时间轴是围绕包装日期创作的艺术叙事，不是食品老化或物理时间的科学模拟。

视觉设计参考了 Image 2 概念图，网页中展示的是实际 3D 模型与实时生成特效，不使用概念图作场景背景。

本目录代码及新增效果采用仓库根目录 MIT 许可证；原模型素材说明见 `docs/REFERENCES.md`。
