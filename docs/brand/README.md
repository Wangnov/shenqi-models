# 三神器标志

2026-09-08 使用 GPT Image 2（gpt-image-2）生成原始设计稿，再按图中的结构手工描摹为可编辑 SVG。原稿见 [image2-concept.png](image2-concept.png)。

- 金色钟盘与行进的指针：时间。
- 绿色立方体与持续整圈旋转：空间。
- 蓝色交织无穷带的整体摆动与沿闭合路径运动的明亮光线：永恒。

矢量原件在 `web/public/brand/logo.svg`。SVG 保留三个独立动画组，无位图嵌入；交织处、色带和线宽经过小尺寸重绘，不是自动轮廓扫描。静态版、favicon 和 Apple Touch 图标由同一份 SVG 派生。

页首和加载页共用同一份 SVG；加载页通过图片直接呈现，无需等待模型或脚本完成。钟针 12 秒一周，立方体 10 秒一周，无穷带 6 秒摆动一轮、光线 3 秒循环。网站标志以 CSS 动画运行。favicon 使用同源预渲染的 48 帧 PNG，每秒更新 8 帧；后台标签停止更新，减少动态效果偏好下使用静态图标。不同浏览器对标签图标更新的展示策略可能不同，始终提供静态 SVG / PNG 回退。

重新生成派生资源：`cd web && npm run brand`。本目录标志与 SVG 代码随仓库采用 MIT 许可证。
